# 量子調和振動子による量子コンピュータ・シミュレータ

量子調和振動子の自由な時間発展によってCNOTを実装する、HTML・CSS・JavaScriptで作成したデモです。
ニールセン＆チャン『Quantum Computation and Quantum Information』7.3節で説明されている符号化と時間発展を使用しています。

```text
|00⟩_L = |0⟩
|01⟩_L = |2⟩
|10⟩_L = (|4⟩+|1⟩)/√2
|11⟩_L = (|4⟩−|1⟩)/√2
```

$$
c_n(\tau) = c_n(0)\exp(-in\tau), \qquad \tau = \omega t
$$

τ = πでは、結果が論理CNOTの出力と一致します。平均エネルギーには零点エネルギーを含めますが、時間発展では全体位相exp(−iτ/2)を省略しています。
忠実度は、選択した入力に対して理想的なCNOTの出力とどの程度一致するかを表すもので、一般的なゲート忠実度ではありません。
損失、環境の影響、状態準備や測定の物理的な装置はモデル化していません。
